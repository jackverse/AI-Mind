# hub — 桌面端

一个窗口看全部：笔记、刷题、错题本、统计、健身、时间线、买房、抖音、小红书、欧路、账单、邮件。
tkinter 单窗口，页面按需懒加载，**零第三方依赖**（只有抖音自动同步需要可选的 `websockets`）。

## 运行

```powershell
python hub\hub.py                       # 默认首页
python hub\hub.py --page notes          # 直接进某页
python hub\hub.py --root D:\path\to\vault
python hub\hub.py --selftest            # 构建全部页面后退出（回归/打包自检）
```

数据仓库的定位顺序：`--root` > 环境变量 `HUB_ROOT` > 从程序目录向上找 `notes/kb/` > 当前目录。
找不到时页面显示空状态，运行时数据建在 `<当前目录>\data\`。

打包后的 `hub.exe` 同理：把 `dist\hub` 整个目录放进数据仓库根目录（或设 `HUB_ROOT`）即可。

## 页面

| 入口 | 内容 |
|---|---|
| **首页** | 科目/题目/错题/笔记数量概览 + 入口卡片 + 最近更新的笔记 |
| **笔记** | `notes/**/*.md` 按目录分组展示，搜索命中自动展开；渲染标题、列表、表格、代码块、引用、行内码 |
| **刷题** | 按科目/章节/题量抽题，选项即时判分、显示解析，写回 `review.json` |
| **错题本** | 未掌握错题明细，按到期时间排序，一键复习 |
| **统计** | 各科目章节掌握度与正确率 |
| **健身** | 从 `notes/daily-log.md` 派生：打卡率、连续天数、体重曲线（7 日均线）、近 30 天热力格、部位分布 |
| **时间线** | 把 `daily-log.md`（日常）与 `index.md`（交流记录）按日期倒序摊开，可筛选、点击直达原文 |
| **买房** | 组合贷/纯公积金月供测算 + 多套房源清单（价格历史、链接、状态、跟进） |
| **抖音** | 登录一次后自动同步作品/趋势/粉丝；多账号融合或分号查看；也可手动导入后台导出表 |
| **小红书** | 绑定账号 + 自动导出后台数据；概览/明细两屏，多账号对照 |
| **欧路** | 多账号 OpenAPI 同步生词本/语料/已掌握，派生新增与连续学习天数 |
| **账单** | 支付宝/微信账单入库，本月收支、每日支出、分类占比、明细；可改分类/备注/排除统计 |
| **邮件** | SMTP 测试与定时提醒，正文从 `TODO.md` 未完成项与 `daily-log.md` 现场生成 |
| **设置** | 侧栏排序、隐私模式、模块管理、数据位置、浏览统计 |

侧栏是卡片式导航，顺序按使用频率自动排列；右键可置顶/隐藏/移到回收站，首页与设置固定。

## 数据仓库约定

```
<vault>/
├─ notes/
│  ├─ daily-log.md         # 健身/时间线数据源
│  ├─ index.md             # 时间线的「交流」数据源
│  ├─ TODO.md              # 邮件提醒的未完成项来源（可选）
│  └─ kb/<科目>/
│     ├─ questions.jsonl   # 一行一题
│     └─ review.json       # 刷题进度（自动生成）
└─ data/
   ├─ hub/                 # 账号库、账单、房源、modules、隐私开关…
   └─ social/              # 浏览器 profile 等大文件（可选）
```

题目格式：

```json
{"id":"q1","chapter":"基础","type":"choice","q":"题干","options":{"A":"…","B":"…","C":"…","D":"…"},"answer":"B","analysis":"解析"}
```

`daily-log.md` 按月一个表，日期列 `MM-DD`，可含体重、训练、英语、抖音等列；解析器只认它认识的列，多出来的列会忽略。

## 隐私模式

侧栏底部一键切换，默认开启：

- 账号昵称/备注名、抖音号、小红书号、手机号、邮箱、8 位以上数字、买房页公积金余额 → 打码展示；
- **只改显示，不动数据**；关掉开关立刻恢复明文；
- 开关按机器分片存 `data/hub/privacy.<主机名>.json`；
- 不是密码锁：截图/投屏防误漏，不防别人翻你的电脑。

## 侧栏模块

内置页面之外，可以加自定义快捷模块（笔记/文件夹/网址/程序）或 `.py` 插件：

- 配置：`data/hub/modules.json`；插件目录：`data/hub/modules/`；
- 支持隐藏、回收站、还原、彻底删除；首页与设置页受保护，不会被误删。

## 构建

```powershell
pip install pyinstaller
powershell -ExecutionPolicy Bypass -File hub\build.ps1
```

产物在 `dist\hub\`：`hub.exe` + `.hub\` 运行时目录（约 1000 个文件）。
不要只拷贝 exe；`.hub\` 必须一起带着。

## 平台与边界

- 桌面端面向 Windows：邮件授权码用 DPAPI 加密，计划任务走 Windows「任务计划程序」；
- 抖音/小红书自动同步依赖本机 Chrome/Edge 与 CDP，登录态加密后落在 `data/hub/`；
- 所有网络请求都是可选的：不登录、不同步时，hub 完全离线可用。
